# スキルツリー・パズル

**固定のスキルツリーに手持ちのポイントを配ってビルドを組み、お題のボスを倒すパズル。**

スキルツリーを伸ばす楽しさのうち、取捨選択・経路の計画・シナジーの発見だけを煮詰めたミニゲームです。
通勤・通学中にスマホのブラウザで、1プレイ5〜10分で遊ぶことを想定しています。
判定はターン制で、乱数を使いません。
同じビルドなら必ず同じ結果になるので、負けた理由を考えて組み直す詰将棋のような遊び方になります。

- **遊ぶ**: <https://mikancode.github.io/daily-coding/20260924-skill-tree-puzzle/>

## 🛠 Tech Stack

- ビルドなしの ES Modules（JavaScript）。型は JSDoc と `@ts-check` で付け、`src/types.d.ts` に集約する
- `package.json` などの依存定義ファイルは置かない

## 💻 検証

Node.js v22.23.3 で動作を確認しています。
`package.json` が無いので、v22.6 では `.js` を ES Modules として読めず、テストが失敗します。

```bash
# テスト。ディレクトリ指定は効かないので glob で渡す
node --test '20260924-skill-tree-puzzle/tests/*.test.js'

# 型検査（エラー0件であること）
npx -p typescript tsc -p 20260924-skill-tree-puzzle/jsconfig.json --noEmit

# お題ごとに全ビルドを総当たりし、最少クリア pt と解を出力する
node 20260924-skill-tree-puzzle/scripts/verify.js
```

## 🕹 遊び方

1. お題のボスの HP・攻撃・反撃・ターン上限を見る
2. ノードをタップして取得する。取得済みのノードをもう一度タップすると外せる。
   組んだビルドの HP・攻撃・防御・属性は、お題の下に出る
3. 「挑戦」を押し、戦闘ログで勝敗を確かめる
4. 負けたら、ログから理由を読んで組み直す

組んだビルドは、ノードを取得・解除するたびにブラウザへ保存されます。
タブを閉じても、次に開いたときに続きから組めます。

## 🎮 ルール

- 起点は最初から取得済み。取得済みのノードに隣接するノードを、配布ポイントの範囲で取る
- 取ったノードは外せる。ただし、外すと起点から繋がらなくなるノードは外せない
- 挑戦すると、自分とボスが1ターンずつ交互に行動する
  - 自分の攻撃は1発ごとに判定する。ボスは被弾するたびに反撃（カウンター）してくる
  - 背水などの条件は1発ごとに、その時点の HP で判定する
  - 属性は、使えるもののうち、ボスの軽減率が最も低いものが使われる
- ボスの HP を0にすれば勝ち。自分の HP が0になるか、ターン上限を過ぎたら負け

## 設計上の制約

- GitHub Pages ではサブパスで配信されるため、import・CSS・リンクはすべて相対パスで書く
- Pages は Jekyll を通すため、`_` で始まるファイル名・フォルダ名は使わない
- データは `.json` ではなく、定数を export する `.js` にする。
  JSON の import attributes は古い iOS Safari で動かず、fetch だと非同期の初期化が要るため
