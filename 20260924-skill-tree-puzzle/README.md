# スキルツリー・パズル

**固定のスキルツリーに手持ちのポイントを配ってビルドを組み、お題のボスを倒すパズル。**

スキルツリーを伸ばす楽しさのうち、取捨選択・経路の計画・シナジーの発見だけを煮詰めたミニゲームです。
通勤・通学中にスマホのブラウザで、1プレイ5〜10分で遊ぶことを想定しています。
判定はターン制で、乱数を使いません。
同じビルドなら必ず同じ結果になるので、負けた理由を考えて組み直す詰将棋のような遊び方になります。

- **遊ぶ**: <https://mikancode.github.io/daily-coding/20260924-skill-tree-puzzle/>

## 🛠 Tech Stack

- ビルドなしの ES Modules（JavaScript）。型は JSDoc と `@ts-check` で付け、`src/types.d.ts` に集約する
- `package.json` などの依存定義ファイルは置かない

## 💻 検証

Node.js v22.23.3 で動作を確認しています。
`package.json` が無いので、v22.6 では `.js` を ES Modules として読めず、テストが失敗します。

```bash
# テスト。ディレクトリ指定は効かないので glob で渡す
node --test '20260924-skill-tree-puzzle/tests/*.test.js'

# 型検査（エラー0件であること）
npx -p typescript tsc -p 20260924-skill-tree-puzzle/jsconfig.json --noEmit

# お題ごとに全ビルドを総当たりし、最少クリア pt と解を出力する
node 20260924-skill-tree-puzzle/scripts/verify.js
```

## 🕹 遊び方

1. お題を選び、ボスの HP・ATK・DEF・能力・ターン上限・軽減率を見る。
   ボスの能力は、ステータスの下にバッジで並ぶ。バッジをタップすると、その能力の説明が出る。
   ボスが複数いるお題では、ボスごとに出る
2. ノードをタップして取得する。取得済みのノードをもう一度タップすると外せる。
   タップしたノードの能力の説明が、ノードの下に吹き出しで出る。
   組んだビルドの HP・ATK・DEF と、能力のバッジ（属性はローテーションの順）は、お題の下に出る。
   能力のバッジも、タップすると説明が出る
3. 「挑戦」を押し、戦闘ログで勝敗を確かめる。
   ボスが複数いるときは、ボスごとの勝敗がタブに並び、タブを押すとそのボスのログに切り替わる
4. 負けたら、ログから理由を読んで組み直す
5. クリアしたら、より少ない pt で解き直す。
   ツリーの上の、残り pt の横に、クリアしたビルドの最少 pt（自己ベスト）が `BEST` として出る。
   全お題をクリアすると、各お題の最少クリア pt が `MIN` として出る。
   最少クリア pt でクリアしたお題には★が付く

組んだビルドは、ノードを取得・解除するたびに、お題ごとにブラウザへ保存されます。
お題を切り替えても、タブを閉じても、戻ってきたときに続きから組めます。
次に開いたときは、最後に選んでいたお題から始まります。
クリアの記録（自己ベスト）も、お題ごとにブラウザへ保存されます。

## 🎮 ルール

- 起点は最初から取得済み。取得済みのノードに隣接するノードを、配布ポイントの範囲で取る
- 取ったノードは外せる。ただし、外すと起点から繋がらなくなるノードは外せない
- 挑戦すると、1ターンは ターン開始 → 自分の行動 → ボスの行動 → ターン終了 の順で進む。自分とボスは同じ能力を同じ処理で使う
  - 行動では、属性などの周期スキルを発動してから通常攻撃する。
    周期スキルは、ツリーの並び順で1ターンに1つずつ順番に使う。周期スキルが無ければ物理で殴る
  - 攻撃は1発ごとに判定する。反撃を持つ側は、被弾するたびに反撃してくる
  - 背水などの条件は1発ごとに、その時点の HP で判定する
  - 再生はターン開始に、毒はターン終了に効く。根性は戦闘中に1回だけ、HP 1 で踏みとどまる
- ボスの HP を0にすれば勝ち。自分の HP が0になるか、ターン上限を過ぎたら負け
- お題のボスが複数いるときは、同じビルドでボス1体ずつと戦い、すべてに勝てばクリア。
  戦うたびに自分の HP は満タンに戻る
- お題ごとに、クリアできる最少の pt（最少クリア pt）が決まっている。
  全お題をクリアするまでは「MIN ?pt」と伏せてある。
  選択肢のお題名の後ろには、クリア済みなら ✓、最少クリア pt でクリアしたら ★ が付く
- お題を調整して最少クリア pt が変わったときは、そのお題の記録が消える
