# utatane.fm — 生成チルBGM プレイヤー

**再生するたびに違う流れになる、終わらないチルBGMをブラウザだけで鳴らす。**

名前は「うたた寝」と「歌の種（生成のシード）」の掛詞。`fm` は流しっぱなしのラジオ局のイメージから。

Tone.js でパッド・メロディ・ピアノ・ドラム・ノイズの5レイヤーを組み立て、単一クロックのスケジューラで同期させながらリアルタイムに生成し続けるジェネラティブミュージックプレイヤーです。ペンタトニックスケール上のコード進行とメロディのランダムウォークにより、同じ「気分」を選んでも毎回異なる展開になります。

## ✨ Features

- **気分（mood）プリセット**: dreamy / rainy day / late night の3種、それぞれ専用のコード進行とスケールを持つ
- **5レイヤー構成**（各レイヤーはUIから個別にon/off可能）
  - パッド: 8声（4声×2グループ）を交互に使ったクロスフェードで隙間なく持続
  - メロディ: 前の音から±1（たまに±2）だけ動くランダムウォークでスケール内を滑らかに移動
  - ピアノ: MonoSynth（のこぎり波+フィルターエンベロープ）で、ガイドトーン（3度・7度）を中心にした簡易ボイスリーディングと、ジャズの「チャールストン」コンピングリズムを模したパターンで演奏
  - ドラム: MembraneSynth/NoiseSynthによるキック・スネア・ハイハットの16ステップシーケンス（裏拍にスウィングを付加）
  - ノイズ: ピンクノイズをハイパスフィルター経由で薄く重ねてテープ/雨のような質感を追加
- **リアルタイム調整**: テンポ・密度（メロディの発音確率）・ノイズ質感をスライダーで変更可能
- 全パートを「16分音符ステップ」という共通の歩数で管理する単一クロック設計により、パート間のズレが生じない

## 🛠 Tech Stack

- **Sound**: [Tone.js](https://tonejs.github.io/) 14.8.49（[cdnjs](https://cdnjs.cloudflare.com/ajax/libs/tone/14.8.49/Tone.js) からCDN読み込みのみ）
- ビルドツール・パッケージマネージャは無し。`package.json` 等の依存定義ファイルは存在しない

## 💻 使い方

`20260901-utatane-fm/index.html` をブラウザで直接開くだけで動作します。インストール・ビルド不要。ヘッドホン推奨。ブラウザタブを閉じると再生も停止します。

スマートフォンでは、ブラウザの自動再生制限により画面を一度タップ（再生ボタンを押下）するまで音が鳴りません。
