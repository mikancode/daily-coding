# Core Concepts

## 用語の前提

- Pointer: ユーザーの入力全般（マウス・タッチ）
- Sound: Tone.js によって生成される音表現
- Visual: Canvas API による視覚表現

### Pointer（入力）
- タッチ / マウスを統一的に扱う
- 座標・押下状態・マルチタッチ拡張を考慮

### Sound（音）
- 座標 → 音階 or 周波数へのマッピング
- Tone.js Synth のライフサイクル管理

### Visual（視覚）
- タッチ位置を起点としたエフェクト
- 音と視覚の同期は「完全一致」を目指さない

## State の考え方

Innocencer では、「画面に見える状態」と「内部処理のための値」を分けて管理する。  
判断の目安は、「その値が変わったときに画面を再描画する必要があるか」。

- **React State**  
  タッチ中かどうか、ポインタの位置など、  
  UI表示に直接使われる状態。

- **ref（一時的な値）**  
  Synth インスタンスや AudioContext の状態など、  
  画面描画とは無関係な内部処理用の値。
