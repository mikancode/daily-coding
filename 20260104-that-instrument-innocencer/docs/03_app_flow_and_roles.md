# App Flow & Roles

## 基本フロー
1. ユーザーが画面に触れる
2. Pointer Event を受け取る
3. 座標をドメインデータに変換
4. 音を鳴らす
5. 視覚エフェクトを描画

## コンポーネントの責務（想定）
- App: 全体の統括
- InputHandler: 入力イベント管理
- SoundController: 音の生成・停止
- VisualRenderer: Canvas描画

## 責務に含めないこと
- 音楽理論の正しさ
- フレーム単位での完全同期

## 拡張時の考え方
- 新しい表現は「音」「視覚」「入力」のどれかに分類する
